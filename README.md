# 女性脑影像队列复现

服务用于管理女性人生阶段研究的访视、影像、同意与分析快照，支持对结论适用范围的复核。
在锁库后若发现扫描设备（如影像线圈更换期间）校准参数登记错误，本服务提供**设备校准版本谱系**
与**定向重算**能力：只重算受影响中心、序列与派生指标，不动未受影响中心的冻结结果。

运行 `python3 service.py --check` 可核对服务配置；执行 `python3 service.py --port 8000`
后访问 `/health` 可确认服务身份。加 `--db snapshot.json` 可把状态持久化到 JSON 快照
（每个重算单元完成即落盘，故障后从最后完成单元继续）。

## 领域规则

- **校准谱系**：设备的校准参数以"生效区间 + 版本"登记；新版本生效时自动闭合前一开放区间。
- **通告去重**：同一 `(设备, 生效起点, 参数指纹)` 的重复通告标记为 `deduplicated`，不重复排队。
- **矛盾暂停**：同一设备区间收到参数不同的通告时，双方隔离为 `quarantined`，已生成计划挂起，
  等待裁决。胜方通告生效；败方参数对应的旧计划作废，并基于胜方重新生成计划（重新走审批）。
- **按采集时点圈定**：重算计划只纳入采集时间落在错误区间、且设备/中心/序列匹配的访视；
  派生指标沿 `derived_from` 依赖闭包传播（含区间外的后续访视）。
- **同意与撤回门槛**：已撤回参与者或采集时点同意范围不足的访视不进入计划；执行前再次校验，
  防止数据借重算回流；其下游派生指标一并挂起。
- **双门禁**：质控负责人确认漂移证据（`qc`）后，统计负责人方可批准分析影响（`statistician`），
  两者齐备计划才可执行。
- **冻结与未冻结分流**：`draft` 指标原子替换受影响输入；`frozen`/`published` 保留原快照，
  仅通过勘误候选（errata candidate）连接新结果。
- **人生阶段比较**：草稿比较原子替换；冻结/已发表比较挂勘误候选；若比较混用了重算指标与被
  阻断指标，则整体挂起（`held_blocked_source`），不静默混合新旧值。
- **检查点恢复**：以访视为重算单元，每完成一个单元即保存；中断后重跑跳过已完成单元。
- **可追溯查询**：`/metrics/{id}/explain` 说明指标是否重算、为何保持原值、采用哪版校准，
  以及对各人生阶段比较的影响。

## 接口

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| GET | `/health` | 服务身份 |
| POST | `/admin/sites` `/admin/devices` | 登记中心、设备 |
| POST | `/visits` `/consents` `/withdrawals` | 登记访视（含采集时点/序列）、同意区间、撤回 |
| POST | `/metrics` `/comparisons` | 登记指标（叶子或 `derived_from` 派生）、人生阶段比较 |
| POST | `/calibration/notices` | 提交校准通告（去重 / 排队 / 矛盾隔离） |
| POST | `/calibration/conflicts/resolve` | 裁决矛盾区间，指定胜方通告 |
| GET | `/devices/{id}/lineage` | 查看设备校准版本谱系与通告 |
| POST | `/recalc/plans` | 由通告生成定向重算计划 |
| POST | `/recalc/plans/{id}/approvals` | 双门禁审批（`role`: qc / statistician） |
| POST | `/recalc/plans/{id}/run` | 执行（可传 `fail_after` 演练故障中断） |
| GET | `/recalc/plans/{id}` | 计划状态、单元检查点、排除/阻断清单、比较影响 |
| GET | `/metrics/{id}/explain` | 指标级重算解释 |

## 测试与构建

执行完整测试：

```bash
npm test
```

执行编译检查：

```bash
python3 -m compileall -q .
```

两条命令都可在单个 Linux 应用容器内直接运行，不需要额外服务。
